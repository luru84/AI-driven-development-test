# Work area

AI が考え・決め・進めた履歴（状態）と生成物を置く作業用ディレクトリです。最低限のテンプレートとして以下を置いています。

- `goal.md` — タスクの目的/スコープ
- `plan.md` — 具体的なステップ計画
- `task.md` — 実行中タスクの詳細（コマンドや入力など）
- `log.md` — 実行ログの要約
- `review.md` — レビューのメモや指摘

運用例:
1. `goal.md` に目的を 1 行で書く
2. `plan.md` に 3〜5 ステップの計画を書く
3. `task.md` にその時点の手順や進行を書き足す
4. 実行記録を `log.md` に集約
5. レビュー時の指摘を `review.md` に書く

本番運用ではセッションごとにサブディレクトリを掘り、これらのテンプレートをコピーして使うと履歴が残りやすいです。
