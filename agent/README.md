# Agent workspace

このプロジェクト専用の AI 役割定義とプロンプト置き場です。状態や進行の履歴は `work/` に置き、ここは役割と方針だけを薄く保ちます。

- `planner.md`: ゴールと 3〜5 ステップの計画を書く。
- `implementer.md`: どのステップを実行中か、生成物のパス、実行したチェックを記録。
- `reviewer.md`: 指摘・質問・判定を整理。
- `decisions.md`: 仕様解釈やスコープ変更などの判断ログ。
- `prompts/`: LLM に渡す system / user プロンプトの保存場所。
- `context/`: リサーチメモや入力データの断片など、参照用のコンテキスト。

状態・履歴は `/work` に残し、`/agent` は「役割定義と参照コンテキスト」のみにしてアーティファクト駆動をシンプルに保ちます。
